# Security Policy

## Supported versions

Security fixes are made for the latest release only.  Please update to the
newest version before reporting a problem.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/jpbarraca/katatone/security/advisories/new).

Include what the problem is, the KataTone version, and the steps to reproduce
it.  `katatone-web` serves a web interface, so say if the problem involves it
and how it was exposed (local only, or on a network).

You can expect an acknowledgement within a few days.  Once the problem is
confirmed, a fix is released and the report is disclosed, crediting you if you
wish.
